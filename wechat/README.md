# v0.4 更新：滚木与密集攻城

新增滚木队，底部六种兵种按钮。滚木自动瞄准城下敌人，横向覆盖约170逻辑像素，仅向城外滚动112像素；每次消耗1根，库存36根，基础装填8秒，单目标基础伤害145，短暂击退减速，对重型器械仅25%伤害。这些均为试玩平衡参数，不是史实测量。

三关敌方单位总数为315／405／480，含步兵、披甲兵、盾兵、弓手、游骑弓手、冲车、投石车。游骑停在城外射击，不骑马撞墙；器械单位数量不等于操作人员数。每批最多30个单位密集进入，实际同屏数量随玩家击杀速度变化，没有虚报万人同屏。

弓兵一轮最多射击3个目标，弩兵最多2个；每发箭独立扣库存。滚木与其他弹药一样，战斗中不自动恢复。老存档可以继续，但不会凭空补发滚木；开始新战斗可体验新配给和新波次。

史料依据、考据边界及数值解释见 [HISTORY.md](HISTORY.md)。预览重建：`node wechat/scripts/build-preview.cjs`（仓库根目录执行）。

# 誓守襄阳 · 微信小游戏原型 0.3

制作日期：2026-11-07。原生 JavaScript + Canvas 2D，单机，无第三方运行依赖，无远程资源。
这是可以导入开发者工具的工程，不是已发布的微信小游戏，也不是正式美术成品。

## 怎么试玩

### 微信开发者工具
1. 解压整个压缩包。
2. 安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
3. 选择导入「小游戏」项目，目录选择本文件所在目录（里面同时有 game.js、game.json、project.config.json）。不要选只含 js 的子目录。
4. 工程已配置你提供的小游戏 AppID：`wxc2db4261985fffa7`。使用该账号的管理员或开发者微信登录开发者工具；导入时确认 AppID 与此一致。AppID 所属账号类型与开发者权限仍需由微信开发者工具验证。
5. 点击编译，进入战役选择。开始时城墙为空，点击底部兵种即可上阵。
6. 有效 AppID 下，使用开发者工具的预览功能生成二维码，在微信中实机测试。

不需要提供 AppSecret，不要把 AppSecret 放进客户端代码。AppID 不是密钥。

### 先在电脑上看玩法
直接双击 `preview/index.html`。这是同一套战斗逻辑的浏览器适配版；不代表微信端已经验证通过。其存档与微信存档互相独立。

## 已实现
- 战役选择、独立战前整备、战斗、结算四个页面。
- 三个独立试玩战役，每场三波，默认1倍速，目标6—8分钟；可切换1/2/4倍速。
- 底部预备队：点兵种上方区域或 + 上阵，− 撤下，「停/开」停火和恢复。
- 最多6队上墙，自动站位、自动攻击，3秒上墙动画；撤下也不会补弹。
- 点击敌军指定集火。可以随时暂停下令，部队恢复后执行移动和攻击。
- 步兵近距离投掷礌石，同时使其他城墙部队装填间隔缩短15%。搬运只影响装填，不生成弹药。
- 弓兵清轻兵，弩兵破甲，投石范围伤害及远程清器械，火器产生有限持续火区。
- 骑兵一次性沿左侧绕后，优先器械与敌弓手；伏兵一次性现身截击。均会受伤、被消耗，无冷却刷新。清完当前敌军后撤离，不再参与后续波次。
- 5处预埋陷坑（可在整备页关闭），踩中伤害165、减速2秒，每坑触发一次。不伤我方侧路骑兵。
- 免费敌情提示，重要投石车进场前预警。
- 城防归零形成中央缺口，仍可继续防守；敌步兵到达城内底线后每人计1，累计10人失败。远程敌军留在城外攻击。
- 失败/撤退后可以重新整备，完整恢复本场初始配给。
- 自动保存进行中的战斗；切后台立即暂停保存；重开可继续上次战斗，恢复时保持暂停。

## 本版边界与后续
- 内政解锁、训练、补充物资暂不实现。本版固定配给；陷坑等级和兵种数值都是测试值。三个战役之间不结转库存或伤兵。
- 不含真实好友分享、援助服务器、广告、内购、支付、账号或排行榜，也不模拟已经收到真实好友援助。
- 无正式火器史料考据；火器为游戏化火罐范围攻击占位。未来再明确历史原型。
- 士卒使用原版 Canvas 绘制；场景为轻量程序绘制，与此前概念效果图有差距。无音效。
- 骑兵/伏兵为队伍总生命值，受损时暂未逐个减少画面上的兵数。
- 没有全场可攻击目标/弹药耗尽时，可暂停或主动撤退后调整；不会自动补弹。
- 原网页版本1保持原样，微信工程在仓库 wechat/ 下独立迭代。

## 验证与限制
已通过：9项核心规则测试、3关通关模拟；Canvas真实绘制；模拟 wx API 的入口启动、触屏、后台暂停、存档、320/390/430/768宽度适配。
尚未通过：微信开发者工具编译、微信客户端真机性能/触摸验证、平台审核及正式发布。当前环境未安装微信开发者工具，已配置本项目 AppID。模拟测试不能替代这些检查。

有 Node.js 可运行 `node tests/core.cjs`。原生入口渲染测试 `node tests/native.cjs` 另外依赖 @napi-rs/canvas（仅开发测试使用，小游戏本身不依赖它）。

## 文件
- game.js：微信原生入口，wx Canvas/触摸/生命周期/存档适配。
- js/core.js：纯战斗逻辑和测试数值。
- js/view.js：Canvas界面、兵种绘制、按钮与触屏坐标。
- js/art.js：沿用原版本1的兵种和器械绘制。
- js/app.js：界面状态与交互。
- tests/：规则、通关和平台适配测试。
- preview/index.html：自包含浏览器试玩，修改源码后需重新生成。
